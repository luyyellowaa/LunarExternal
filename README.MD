## Overview

**LunarExternal** is a modern external cheat framework built with performance and stealth in mind. Designed for developers and reverse engineers, it provides a clean, modular architecture that makes it easy to extend and maintain.

## Features

- **High Performance** — Minimal CPU and memory footprint
- **Stealth Focused** — No direct memory writes from the cheat process
- **Modular Design** — Easy to add new features
- **Overlay Rendering** — Smooth ESP with DirectX 11
- **Config System** — Save and load settings on the fly
- **Clean Codebase** — Readable, well-documented code
